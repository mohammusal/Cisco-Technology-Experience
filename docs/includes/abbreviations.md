*[program]: A list of instructions that a computer follows, one after another.
*[programs]: Lists of instructions that a computer follows, one after another.
*[interpreter]: The program that reads your Python code and runs it line by line. When you install Python, you install the interpreter.
*[terminal]: A window where you type commands for the computer. In VS Code it opens at the bottom of the screen.
*[syntax]: The grammar rules of a programming language: where colons, brackets and quotes must go.
*[bug]: A mistake in a program that makes it do the wrong thing or stop.
*[comment]: A note for humans, starting with #. Python ignores it.
*[variable]: A named box that stores a value, for example name = "Ola". You can put a new value in the box at any time.
*[variables]: Named boxes that store values, for example name = "Ola". You can put a new value in a box at any time.
*[value]: A piece of data, for example 7, 3.5, "hello" or True.
*[string]: Text inside quotes, for example "Krakow" or 'hello'.
*[strings]: Pieces of text inside quotes, for example "Krakow" or 'hello'.
*[integer]: A whole number without a decimal point, for example 7 or -3. In Python its type is int.
*[float]: A number with a decimal point, for example 3.14. In Python its type is float.
*[Boolean]: A value that is either True or False. In Python its type is bool.
*[operator]: A symbol that does something with values, for example + - * / == or and.
*[operators]: Symbols that do something with values, for example + - * / == or and.
*[condition]: A question with a True or False answer, for example age >= 18.
*[indentation]: The spaces at the start of a line. Python uses them to know which lines belong together in a block.
*[block]: A group of lines indented by the same amount that run together, for example everything inside an if.
*[loop]: Code that repeats. A while loop repeats while a condition is True; a for loop repeats once for each item.
*[loops]: Code that repeats. A while loop repeats while a condition is True; a for loop repeats once for each item.
*[iteration]: One trip through a loop.
*[list]: An ordered collection of values in square brackets, for example [1, 2, 3]. You can change it.
*[lists]: Ordered collections of values in square brackets, for example [1, 2, 3]. You can change them.
*[index]: The position number of an item in a list or string. Python starts counting at 0.
*[slice]: A part of a list or string, taken with [start:stop], for example word[0:3].
*[method]: A function that belongs to a value. You call it with a dot, for example name.upper().
*[tuple]: An ordered collection in round brackets that cannot be changed, for example (3, 4).
*[tuples]: Ordered collections in round brackets that cannot be changed, for example (3, 4).
*[dictionary]: A collection of key and value pairs, for example {"cat": 4, "bird": 2}. You look up a value by its key.
*[dictionaries]: Collections of key and value pairs, for example {"cat": 4, "bird": 2}. You look up a value by its key.
*[key]: The label you use to find a value in a dictionary.
*[set]: A collection of unique values in curly brackets, for example {1, 2, 3}. It has no duplicates and no order.
*[function]: A named piece of code that does one job. You define it once with def and can use it many times.
*[functions]: Named pieces of code that each do one job. You define them once with def and can use them many times.
*[parameter]: A name inside the brackets of def that receives a value when the function is called.
*[parameters]: The names inside the brackets of def that receive values when the function is called.
*[argument]: The value you give to a function when you call it, for example the 5 in square(5).
*[arguments]: The values you give to a function when you call it, for example the 5 in square(5).
*[constant]: A variable written in CAPITALS, for example ROUNDS = 5, that the program never changes.
*[PATH]: The list of folders where your computer looks for programs such as python.
*[return value]: The answer a function gives back with return.
*[exception]: An error that happens while the program runs. You can catch it with try and except.
*[exceptions]: Errors that happen while the program runs. You can catch them with try and except.
*[module]: A Python file with ready-made code you can use, for example random or time. You load it with import.
*[API]: A menu of requests a service accepts, for example "create a room" or "send a message".
*[REST]: A style of API that uses HTTP methods such as GET, POST, PUT and DELETE on URLs.
*[JSON]: A text format for data using braces, brackets and quoted keys. Webex answers in JSON.
*[token]: A secret string that proves who the program is. Keep it in token.txt, never in the script.
*[SDK]: A library that wraps an API in Python functions, for example webexteamssdk.
*[bot]: A Webex account meant for a program, with its own email and its own token.
*[webhook]: An HTTP POST that a service sends to your URL when something happens, for example a new message.
*[Flask]: A Python library that turns functions into a small web server.
*[FastAPI]: A Python library for building APIs, often run with uvicorn.
*[Bruno]: A free, offline-friendly REST API client with no login required, used to test API calls before coding them in Python.
*[HTTP]: The protocol browsers, Bruno, and Python use to send requests (GET, POST, PUT, DELETE) and receive responses over the web.
